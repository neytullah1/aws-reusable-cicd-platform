# ADR-001: Shared delivery contracts, runtime-specific deployment

**Decision:** Centralize build, policy and provenance contracts; use adapters for EKS, ECS and Lambda. Immutable digest is the release identity. Promotion uses a protected PR plus manual approval, not rebuild. For EKS GitOps is the reconciler; ECS and Lambda use constrained deployment controllers.

**Trade-off:** Extra integration complexity and a security-owned verification service; avoids falsely assuming the same deployment semantics for three runtimes.

**Rejected:** Caller-owned approvals, self-attested security checks, per-environment rebuilds, unscoped AWS credentials, and LLM as policy decision-maker.
