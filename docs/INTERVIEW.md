# Interview talking points

1. **Why adapters?** Uniform security contract, heterogeneous runtime deployment semantics.
2. **How can developers bypass YAML?** They can edit callers; enforcement must be external in org rulesets, trusted checks, IAM and runtime admission.
3. **Why manual approval?** Explicit accountability, but approvals alone cannot protect AWS if the role is overprivileged.
4. **What is real here?** Schema tests and reference workflow code. No live AWS deployment or proven attestation verification.
5. **Why advisory AI?** It increases review context without becoming a non-deterministic authorization control.
